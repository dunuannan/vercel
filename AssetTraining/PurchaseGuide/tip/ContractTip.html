检查发现的主要问题

01

合同金额与中标金额不一致

合同金额、价款性质或者计价口径偏离成交结果，常见表现为总价与单价混淆、价款名称改变、合同总额与采购结果不一致。

提示问题

  • 合同金额与中标金额不一致，存在单价、总价混淆等情况。
  • 合同价款名称被替换为其他收费表述，导致合同义务边界不清。
  • 计价方式一旦偏离采购文件，后续结算、审计和履约评价均会失去统一依据。
风险提示：合同价款口径变化属于实质性内容偏移，容易引发支付依据不充分、结算争议和审计质疑。

脱敏案例

案例 A / 服务保障类

某服务类项目的招标结果以合同总额为基础确定成交，但合同文本却将价款表述为“资源占用费”，并按单价口径呈现，导致合同金额性质与采购结果明显不一致。

02

合同服务、供货或施工期限与招标文件不符

合同期限出现缩短、延长、前后不一致，或者在招标文件之外新增限制条件，都会破坏原采购文件与合同文本的一致性。

提示问题

  • 合同服务、供货或施工期限与招标文件不符。
  • 部分合同存在期限前后表述不统一、擅自增加服务内容或附加条件等问题。
  • 期限条款失真会直接影响履约计划、违约认定和项目验收节奏。
风险提示：期限约定被任意调整，可能形成对采购文件的实质性修改，也会放大履约延期与责任认定争议。

脱敏案例

案例 A / 系统建设类

某建设类项目招标文件要求在支付首付款后100个自然日内完成交付，但合同改写为60个自然日内完成，供货期限被明显缩短。

案例 B / 驻场服务类

某服务类项目合同服务期长度仍为一年，但起止日期整体后移 2 天，看似差异不大，实则已偏离招标文件的时间安排。

案例 C / 改造施工类

某施工类项目合同工期条款新增“具体结合场地条件为准”等表述，该附加条件并未出现在招标文件中，改变了交付边界。

案例 D / 内容交付类

某内容交付类项目合同约定的完成期限长于招标文件要求，项目交付周期被延展，影响采购时承诺的进度安排。

案例 E / 履约期限类

某项目合同文本内部存在不同页面工期表述不一致的情况，签署后难以判断究竟应以哪个履约期限作为执行依据。

03

合同付款方式与招标文件不一致

付款比例、付款节点、支付条件如与招标文件不一致，或合同内部出现多个版本并存，会削弱合同作为支付依据的严肃性。

提示问题

  • 合同付款方式与招标文件不一致。
  • 合同内付款条款前后矛盾，无法形成唯一明确的付款条件。
  • 付款节奏被修改后，资金支付责任、履约担保责任和验收关联关系都会受到影响。
风险提示：付款条款属于合同核心商业条款，前后不一致或偏离采购文件，极易造成超节点支付、提前支付或支付争议。

脱敏案例

案例 A / 常规运维类

某服务类项目招标文件约定按月支付，合同文本却改为“5% + 95%”的分段支付方式，付款节奏发生了实质性变化。

案例 B / 建设实施类

某项目合同第前部条款与后部条款对付款时间的写法不一致，形成两个相互冲突的支付口径。

案例 C / 场景建设类

某建设类项目合同中的付款安排与招标文件约定不一致，未能完整延续采购环节中已经明确的支付条件和支付节点。

04

合同服务、供货条款明细及技术参数填写不完整

条款不全、参数缺失、服务内容不细化，会导致合同难以作为执行与验收的精确依据，尤其在设备采购和专业服务项目中更为突出。

提示问题

  • 合同服务、供货条款明细及技术参数填写不完整、不规范。
  • 关键参数、服务边界和交付要求缺失，容易导致履约内容被泛化。
  • 条款不完整时，即使发生争议，也难以据此确认应交付的范围和标准。
风险提示：技术参数和服务清单是合同执行的基础，一旦缺漏，将直接削弱质量控制、验收和索赔能力。

脱敏案例

案例 A / 设备采购类

某设备采购类项目中，合同对于一项核心设备的技术参数描述缺少其中一条关键参数，造成规格要求不完整。

案例 B / 维保服务类

某维保类项目合同仅写明服务事项名称，未进一步列明具体服务内容、频次和范围，服务条款明显过粗。

案例 C / 物资供应类

某供货类项目中，合同对重要产品的规格参数描述不完整，无法支撑后续到货核验和质量追责。

05

合同未明确约定验收标准

验收标准缺失时，项目完成与否、成果是否合格、付款是否触发都失去可以操作的判断基准，是最容易在履约后期形成争议的条款缺口。

提示问题

  • 合同未明确约定验收标准，缺乏可操作的验收依据。
  • 服务成果、交付节点、完成标准之间未形成闭环。
  • 没有验收标准，质量不达标也难以形成有效的书面认定。
风险提示：验收标准缺位会使付款触发条件和违约责任都失去抓手，后续治理成本显著上升。

脱敏案例

案例 A / 综合服务类

某服务类项目合同全文未设置验收标准或质量评价条款，导致服务完成后缺少明确的判断依据。

案例 B / 咨询服务类

某咨询类项目合同对于成果提交和合同终止有表述，但没有同步写明成果验收标准和验收程序。

案例 C / 活动执行类

某执行类项目合同仅约定活动完成时间，未写明验收依据、交付清单和质量标准，不利于付款审核和结果评价。

06

合同未按规范编制合同编号

合同编号是档案管理和全流程追溯的重要基础项，看似形式问题，实际直接影响归档、查询、监督和责任留痕。

提示问题

  • 合同未按规范编制合同编号。
  • 缺少编号会影响合同台账管理、归档一致性和跨部门追踪。
  • 在多项目并行场景下，无编号合同极易造成附件错配和审批留痕缺失。
风险提示：编号不规范虽不直接改变交易条件，但会削弱合同全生命周期管理和档案可追溯性。

脱敏案例

案例 A / 平台服务类

某平台服务类项目合同签署文本中未见合同编号，无法与合同台账、采购审批材料和归档目录形成稳定对应关系。

相关制度条款

制度依据 01

《中华人民共和国政府采购法》

第四十六条

采购人与中标、成交供应商应当在中标、成交通知书发出之日起三十日内，按照采购文件确定的事项签订政府采购合同。

制度依据 02

《政府采购非招标采购方式管理办法》

第十九条

采购人与成交供应商应当在成交通知书发出之日起30日内，按照采购文件确定的合同文本以及采购标的、规格型号、采购金额、采购数量、技术和服务要求等事项签订政府采购合同。

采购人不得向成交供应商提出超出采购文件以外的任何要求作为签订合同的条件，不得订立背离采购文件确定内容的协议。

制度依据 03

《政府采购货物和服务招标投标管理办法》

第七十一条

采购人应当自中标通知书发出之日起30日内，按照招标文件和中标人投标文件的规定，与中标人签订书面合同。所签订的合同不得对招标文件确定的事项和中标人投标文件作实质性修改。

采购人不得向中标人提出任何不合理的要求作为签订合同的条件。

工作要求

请各部门严格遵守上述法律条款要求，确保合同签订的合法性、准确性，从而保障项目质量，规避履约风险。对照本页所列问题和案例，重点核查合同金额口径、履约期限、付款节点、技术参数、验收标准和合同编号等关键字段，避免在合同签订阶段出现与采购文件不一致、与合同文本内部不一致、与履约管理需求不匹配的情况。

国有资产管理处将继续对涉及部门和项目逐一反馈整改意见，持续提升学院招标采购管理质效，切实保障国有资产安全和资金使用效益。
